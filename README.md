# Manga Extensions

Source code for a repository of manga extensions for Tachiyomi-compatible apps. It is an independently
maintained fork of `keiyoushi/extensions-source`.

[![CI](https://github.com/eleanorlydie-wq/extensions-source-revived/actions/workflows/build_push.yml/badge.svg)](https://github.com/eleanorlydie-wq/extensions-source-revived/actions/workflows/build_push.yml)

## Usage

Add this repo in your app's extension settings by pasting the following URL:

    https://raw.githubusercontent.com/eleanorlydie-wq/extensions/repo/index.min.json

The APK files are listed in the [`repo` branch](https://github.com/eleanorlydie-wq/extensions/tree/repo/apk).

## Requests

To request a new source or bug fix, [create an issue](https://github.com/eleanorlydie-wq/extensions-source-revived/issues/new/choose).

Please note that creating an issue does not mean that the source will be added or fixed in a timely
fashion, because the work is volunteer-based. Some sources may also be impossible to do or prohibitively
difficult to maintain.

If you would like to see a request fulfilled and have the necessary skills to do so, consider contributing!
Issues are up-for-grabs for any developer if there is no assigned user already.
